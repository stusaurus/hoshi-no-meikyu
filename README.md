# 星の迷宮 — STANDARD（Web試作品）

> **開発中 / 公開試遊用プロトタイプ**。カード枚数、盤面サイズ、星・壁の配置ルールは検証用の暫定設定です。

## コンセプト
足の生えたロケットが星を集める、秘密情報と駆け引きのボードゲーム。
星の得点や壁の正体は隠され、星を確保するとその場に自分の旗が立って移動の障害物に変化します。得点は最終ラウンドまで公開されません。

## スターターセット（初めて遊ぶ方向け）

**Web版ではスターターを初期選択**。ゲームに慣れた人向けに従来のスタンダード（カード8種類・壁4種類）も選択可能です。

- カード **5種類**：てくてく、流星ダッシュ、ジェットジャンプ、宇宙探査、トラクタービーム（合計44枚）
- 秘密の壁 **3種類**：通常壁、反発壁、幻影壁
- 初期手札はてくてく2枚、ダッシュ・ジャンプ・探査を各1枚。トラクタービームは山札から登場
- 星の点数・獲得後の旗・2アクション制など、ゲームの核は変更しません

物理製品版も意識した構成や人数別の内訳は[スターター正式試作仕様](docs/STARTER-SET.md)を参照。

## このブランチで遊べるもの
- 2〜4人で1台の端末を交代して対戦、または人間1人＋初級CPU1〜3体で対戦
- 検証用7×7 / 8×8 / 9×9盤面
- 固定の初期手札、2アクション制、6ラウンド
- 裏向きの星（0〜3点）と裏向きの壁（通常・反発・一方通行・幻影）
- 壁を移動、星を引き寄せる、相手ロケットを動かす、探索、バリア、3種類の移動
- 第4ラウンド前の追加配置、旗による通行妨害、最後の得点公開
- 交代画面で前のプレイヤーの手札・秘密情報を通常画面から隠す

## CPU対戦（初級）

トップ画面の「遊び方」で「1人＋CPU 1〜3体」を選択してください。CPUが星や壁を配置し、手番で自動行動します。

- 星に近づく移動を優先し、流星ダッシュ・ジャンプ・探査・妨害などを状況によって使う
- CPUが知らない星の点数は期待値として扱い、未公開の壁の種類は先読みしない
- まだ**初心者向けの試作CPU**。CPUの強さ、勝率、最適な盤面は検証していない
- 友達同士の交代プレイも従来どおり使える

## 開発者向け
追加のインストールなしで `index.html` をブラウザで開きます。ローカルサーバーを使う場合：

```bash
python3 -m http.server 8000
# http://localhost:8000/
```

Node.jsを利用した操作・ルールの基本スモークテスト：

```bash
node tests/smoke.mjs
node tests/smoke.cjs
node tests/interactions.cjs
node tests/cpu.cjs
```

## 制限と次の工程
- このGitHubブランチはローカルで交代して遊ぶための**基本実装**です。遠隔オンライン対戦・会員登録・購入機能はありません。
- 暗号的な秘密保護はありません。ブラウザの開発者ツールから情報を見られるため、遠隔対戦ではサーバー側の権限管理が必要です。
- 正式な「足のあるロケット」のイラストはまだ仮表示です。
- 初級CPU対戦に対応。過去の900＋432試合は**旧スタンダード版のみ**の結果です。スターター版の対戦時間とバランス、人間の遊びやすさは新たに検証します。
- **試遊URLは公開済み**。正式製品としての公開、販売機能、「きょうボド」へのリンク追加は人間のテストプレイ後に判断します。
