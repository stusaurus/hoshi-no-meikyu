# 星の迷宮 — STANDARD (開発中)

足の生えたロケットを動かし、得点が隠された星を確保するオリジナル対戦ボードゲーム。

> **注意:** このリポジトリのゲームは開発途中のWeb試作品です。完成した製品ではありません。GitHub Pagesへの公開はまだ行っていません。

## Web試作品のルール

- 2〜4人の同一端末交代プレイ
- 検証用盤面 7×7・8×8・9×9（適正サイズは未確定）
- 裏向きの星：0〜3点。配置した本人は点数を知っている
- 得点の最終公開：確保した星を裏返さず旗を立て、6ラウンド終了時に開示
- 旗は全員にとって障害物。流星ダッシュの停止位置を変える
- 壁4種類：通常・反発・一方通行・幻影。基本は接触で公開
- 移動カード3種：てくてく、流星ダッシュ、ジェットジャンプ
- 効果カード5種：宇宙探査、トラクタービーム、壁の移動、星の引力、宇宙バリア
- 1ターンに最大2アクション。初期手札5枚、固定モードから検証
- 閉じ込め時の緊急ブースト・緊急帰還（仮）

## 手元で動かす

同じフォルダに `index.html`、`style.css`、`game.js` を置いて `index.html` をブラウザで開きます。
通信や外部APIは不要です。サイト公開、対戦サーバー、販売ページは未設定です。

## 現段階の検証範囲

秘密情報のブラウザ内保存は同じ端末で交代して使うための仮方式です。DevTools等からは参照できます。
オンライン対戦時には、手札・星・壁の秘密をサーバー側で保持する設計が必要です。

本リポジトリの試作は、運営中の「きょうボド」(stusaurus/kyo-bodo-jp) とは分離し、既存サイトに影響しない構成です。

## ゲームの開発方針

1. まずスタンダードの面白さを磨く（拡張の実装は保留）
2. 星の配置と旗の障害物化、秘密の壁、行動カードの読み合いを検証
3. 2・3・4人 × 7×7・8×8・9×9 の対戦を別々に比較し、星・壁・ラウンド数も調整
4. Web版で検証した後、紙のカード・立体ロケット・旗を使った物理試作
5. 将来はきょうボドからWeb体験へ誘導し、実物版の購入につなげる

## 実装予定
