# 星の迷宮 — STANDARD（Web試作品）

> **開発中 / 未公開のプロトタイプ**。カード枚数、盤面サイズ、星・壁の配置ルールは検証用の暫定設定です。

## コンセプト
足の生えたロケットが星を集める、秘密情報と駆け引きのボードゲーム。
星の得点や壁の正体は隠され、星を確保するとその場に自分の旗が立って移動の障害物に変化します。得点は最終ラウンドまで公開されません。

## このブランチで遊べるもの
- 2〜4人で1台の端末を交代して対戦
- 検証用7×7 / 8×8 / 9×9盤面
- 固定の初期手札、2アクション制、6ラウンド
- 裏向きの星（0〜3点）と裏向きの壁（通常・反発・一方通行・幻影）
- 壁を移動、星を引き寄せる、相手ロケットを動かす、探索、バリア、3種類の移動
- 第4ラウンド前の追加配置、旗による通行妨害、最後の得点公開
- 交代画面で前のプレイヤーの手札・秘密情報を通常画面から隠す

## 開発者向け
追加のインストールなしで `index.html` をブラウザで開きます。ローカルサーバーを使う場合：

```bash
python3 -m http.server 8000
# http://localhost:8000/
```

Node.jsを利用した操作・ルールの基本スモークテスト：

```bash
node tests/smoke.mjs
```

## 制限と次の工程
- このGitHubブランチはローカルで交代して遊ぶための**基本実装**です。遠隔オンライン対戦・会員登録・購入機能はありません。
- 暗号的な秘密保護はありません。ブラウザの開発者ツールから情報を見られるため、遠隔対戦ではサーバー側の権限管理が必要です。
- 正式な「足のあるロケット」のイラストはまだ仮表示です。
- CPU対戦・人数別シミュレーションを含む**発展版の試作パッケージ**は別途作成済みですが、このブランチにはまだ統合していません。
- 本番公開や「きょうボド」へのリンク追加は、実画面・操作・ルールの検証後に行います。
