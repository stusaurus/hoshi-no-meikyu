# 星の迷宮 — STANDARD Web試作版

> 星を隠し、道を惑わせ、相手の一手を読み切れ。

「星の迷宮」はオリジナル対戦ボードゲームの**開発中の試作品**です。完成版・販売版ではありません。

## 今できること

- 同じ端末で2〜4人が交代して遊ぶ（手番交代時は非表示画面）
- 検証用の7×7 / 8×8 / 9×9マス盤面
- 0〜3点の星を自分だけ確認して裏向きに配置
- 4種類の秘密の壁を設置／接触時に公開
- 手札5枚、1手番に最大2枚のカードを使用
- 基本カード8種類：てくてく、流星ダッシュ、ジェットジャンプ、宇宙探査、トラクタービーム、壁の移動、星の引力、宇宙バリア
- 星に停止したら裏向きのまま自分の色の旗を立てる。以後そのマスは障害物
- 第4ラウンド前に星と壁を再配置し、6ラウンド終了時に星を一斉公開

## 起動方法

`index.html` をブラウザで開くか、ローカルWebサーバーを起動します。

```bash
python3 -m http.server 8000
# http://localhost:8000/
```

## 操作方法

1. 人数と盤面サイズを選んで開始。
2. 「秘密配置」の手番では星・壁を選び、盤面のマスをタップして置く。壁は矢印で設置方向を指定。
3. 交代画面が出たら端末を次の人へ渡す。
4. 手札を選択して移動先や効果対象をタップ。流星ダッシュ／ジャンプは方向を選ぶ。
5. 移動カードの処理が終わったときに星のマスにいれば、旗を立てて確保する。
6. 6ラウンド終了で、確保した星の得点を公開して勝敗を決定。

### 秘密情報の扱い
自分で置いた星・壁と、探査カードで確認した情報だけが、自分のターン中に表示されます。共通の星は全員が知らない状態で開始します。壁はマス間に配置し、公開後の種類は全員に見えます。

ローカル版は画面を隠す方式であり、端末の開発者ツール等に対して秘密情報を暗号学的に保護するものではありません。

### 試作中の脱出ルール
公開情報で全方向が塞がれているとき、緊急ブーストまたは緊急帰還を選択できます。帰還には減点があります。個人の途中脱落は未採用です。
