# 星の迷宮 — 拡張パック候補（保管庫）

このファイルは将来のアイデアを忘れないためのもの。**STANDARDの完成まで実装しない。**

## 1. 盤面の追加
- **5×5 接近戦**：短距離カード・強制移動・壁位置の読み合いを強化
- **穴あき銀河**：進入不能マス、島状・回廊状・非対称盤面
- **変則形状**：細い通路、複数の広場、隔絶されたエリア、橋
- **盤面サイズの変化**：7×7、8×8、9×9、人数別セットアップ。適正値はシミュレーション後に決める

## 2. 追加の特殊地形と壁
- ワープゲート／ワープ壁
- 回転する壁・銀河円盤
- 時間経過で向きが変わる一方通行
- 星の結晶壁：隣接星の得点を補正
- 反発・重力操作・移動する壁の発展版
- 一時的に置く橋／流星に破壊される通路

## 3. モード選択
- **未開の星探索モード**：ほぼすべての星・壁が裏向き。ブラフと情報戦を強化
- **惑星探索モード**：一定割合の星・壁を公開。先読みと戦術を強化
- **初期手札固定モード**：全員が同じ5枚から開始
- **ランダム初期手札**：移動カードの最低保証など、事故防止つき
- 自由探索：盤面、情報量、手札配布方式を独立に組み合わせる
- 作戦セット（スピード・トリック・コントロール型の初期デッキ）

## 4. イベント・カード
- 流星群・宇宙嵐・重力異常などの全体イベント
- 穴あき専用：星の架け橋・軌道ジャンプ・重力反転
- 大盤面専用：彗星ダッシュ・遠隔スキャン・長距離重力ビーム
- 接近戦専用：位置交換・小さな突風・壁の引っ越し
- 探索用：星のすり替え・位置交換・情報公開
- 協力・シナリオ・星座完成・秘密の目的カード（本編と相性を要検討）

## 5. バリエーション設計の原則
- 基本ルールは統一して覚えやすくする
- カードには「全フィールド共通」「特定フィールド専用」の互換性表示を付ける
- 追加要素でゲームが停止したり無限移動になったりしない安全条件を用意
- 最初から大量のモードをUIに載せない。おすすめセットアップを用意
- 面白さが実測・対人テストで確かめられたものから採用する

## STANDARDに残す候補
- 足が生えたロケット駒
- 星の点数を最後まで隠すルールと、獲得済みの星に旗を立てる
- 旗が障害物となる、流星ダッシュの停止位置を変える
- 秘密の壁（通常・反発・一方通行・幻影）
- 移動カードと効果カードの組み合わせ、相手ロケットの強制移動
- 閉じ込め時の脱出行動／ゲームオーバー（初期版は早期脱落を保留）
