# 星の迷宮 — 拡張アイデア保管庫

**重要：このファイルは将来のアイデア保管用。今はスタンダード版の品質改善を最優先する。**

## フィールド展開
- 5×5：短時間の近距離戦、壁移動と強制移動を中心にした接近戦
- 7×7：スタンダードの比較候補
- 8×8 / 9×9：人数別最適化・旗の閉塞対策として比較する
- 穴あき・不規則なフィールド：通れない虚空・島・裂け目
- 架け橋・宇宙の橋、ジャンプ、移動する地形
- 回転銀河盤、回転する壁、通路の変更
- 対応フィールドごとにカードを差し替えるシステム

## 秘密情報と難易度
- **未開の星探索モード**：星の得点・壁の効果をほぼすべて隠す
- **惑星探索モード**：星や壁の一部を公開して先読みしやすくする
- 初期手札固定：初心者向け、公平な比較用
- 初期手札ランダム：即興作戦・リプレイ性
- 上記を組み合わせた自由探索モード
- 追加の作戦セット（スピード／トリック／盤面コントロール）

## 拡張パック候補
1. **欠けた銀河** — 穴あき・裂け目・橋・軌道ジャンプ
2. **時空の迷宮** — ワープゲート・一方通行強化・回転壁・ロケット位置交換
3. **流星群の襲来** — ラウンドごとのイベント・星の生成・星の位置変動
4. **秘密の星座** — 星座のセット収集や秘密目標
5. **未開の惑星** — より多くの観測・偽装・情報交換カード
6. **協力探索** — 全員で失われる星を救うシナリオ
7. **宇宙のレース** — 同時行動・プログラム移動

## 以前出たカード・壁の案
- 幸運の壁（通るとカードを引く）
- 星の結晶壁（星の獲得に追加点）
- 反発・ワープ・幻影・変化する壁
- 星のすり替え、星の位置交換、壁の透視
- 重力異常、宇宙突風、緊急転送、ロケットの位置交換
- 緊急脱出とゲームオーバー条件のサバイバル版

## 将来の製品化
- 足の生えたロケットのオリジナル立体コマ（「きょうボド」のデザインを参照）
- フィールド拡張セット、色別の旗、裏向きの星カードと壁パーツ
- Web無料体験から実物版の販売ページにつなげる
- 「きょうボド」トップページのオリジナルゲーム入口
- 新作ゲームを増やしても独立したゲームリポジトリで管理

## 採用時の条件
スタンダード版の平均プレイ時間・ルールの理解しやすさ・2〜4人の適性が検証できてから着手。単に種類を増やすのではなく、基本版と違う判断・駆け引きが生まれるものを採用する。
