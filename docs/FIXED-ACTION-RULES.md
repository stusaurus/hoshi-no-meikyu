# 公開得点・固定アクション 試遊仕様（2026-10-15）

ユーザーの試遊所感「星のランダム配布＋相手の星が分からず、最後に結果が分かることによる運の強さ」を受けた新版。旧スターターと旧スタンダードは比較用に保持する。盤面7/8/9は引き続き検証用。

## 承認された星の仕様

- 全員が **1点・2点・3点を1枚ずつ**持つ。同じ構成で、星の配布に乱数を使わない。
- **前半の初期配置で2枚、後半開始で残り1枚**を置く。どの得点を前半に置くかは本人が選ぶ。
- 盤上の星の得点と、獲得後の現在の合計得点を全員に公開する。終了時の得点公開による当たり外れをなくす。
- 新版にランダムな共通星を追加しない。星は2人6枚・3人9枚・4人12枚、総得点はそれぞれ12・18・24点。
- 配置者に所有権はない。移動を終えた星をそのロケットが獲得し、旗を立てる。自分の旗も通行を妨げる。

## 固定カードの試遊上の具体化

「カードを固定して、どうすれば勝てるか考えたい」を **全員に同じ5種類を常時提供**する形で実装。山札、引き直し、捨て札、ランダム補充はない。使ってもカードは減らず、次の手番でも同じ行動を選べる。連続使用禁止や使用回数の管理は導入していない。

| 行動 | 効果 |
|---|---|
| てくてく | 曲がりながら最大2歩、途中で止まれる |
| 流星ダッシュ | 障害物か盤端まで直進。途中の星は取らない |
| ジェットジャンプ | 直線最大2マス、障害物を最大1つ越える |
| 宇宙探査 | 秘密の壁を1枚、自分だけ確認。星は公開済みなので対象外 |
| トラクタービーム | 縦横3マス以内の相手を1マス動かす。星で止まれば相手の得点になる |

1手番は **1カードアクション**。てくてく2歩は1アクションであり、1歩ごとに交代するルールではない。パスも可能。選んだ行動を終了後に手番終了ボタンで交代する。手番内の2枚目は無効化する。

全員が1回ずつ行動する「巡」を最大12回。前半6巡、7巡開始前に追加配置、後半6巡。既存比較と最大12行動枠を合わせた試遊設定で、正式な対戦時間を意味しない。後半に全星が獲得されたら、その巡で全員に同じ手番数を与えた後に終了する。

## 壁・行き詰まり

3種類の秘密壁と各人2枚（初期1枚・後半1枚）の既存仕様を維持。壁の種類の配布は現行と同じで、ここはまだ固定配布に変更していない。

緊急ブーストは公開情報で通常歩行出口を塞がれたとき、2マス先の星のない安全な空きマスへ脱出する。固定カードは減らさず、この手番の1アクションを使う。緊急帰還はジャンプなどの脱出手段も安全なブースト先もない場合だけ利用可能、現在の得点から2点を引く。安全な復帰先がない全状態を数学的に保証したものではない。

この救済は固定カードで進行不能を避けるための試遊設定。包囲に強すぎないか、同じ移動を繰り返すことによる停滞、公開星に対するCPUの近距離回収偏重、壁専用探査の価値は別のゲーム性検証が必要。旧ルールの勝率や8,613件・2,784件の結果を新版の公平性の証拠に流用しない。
